O que é o Git?

O Git é um sistema de controle de versão distribuído gratuito e de código aberto projetado para ser rápido e eficiente.

O que é o GitHub?

O GitHub é uma plataforma de hospedagem de código-fonte com controle de versão usando Git.

O que é um repositório?

Um repositório é um local onde o código-fonte de um projeto é armazenado e gerenciado.

O que é um commit?

Um commit é uma alteração no código-fonte que é registrada no histórico de versões.
